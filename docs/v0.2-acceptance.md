# Jarvis Studio v0.2 Acceptance

## Objective Evidence

| Requirement | Evidence |
|---|---|
| `agent-runtime` minimal Agent Loop | `packages/agent-runtime/src/runtime.ts` and runtime tests |
| OpenAI-compatible model calls | `providers.ts` chat-completions implementation and provider contract test |
| Skill loading and Context construction | Versioned manifests/SKILL files and segmented Context Snapshot tests |
| Tools | Real bounded implementations of `filesystem.read`, `filesystem.write`, `python.run`, and `xlsx.inspect` |
| Initial Skills | `excel-data-analysis`, `weekly-report`, and `code-review` |
| Studio creates real Run | Runtime Console and `POST /api/runtime/runs` |
| Live Trace Events | SSE `GET /api/runtime/runs/:runId/events` |
| Context Snapshot before every LLM call | Runtime emits/persists `context.build` immediately before each `llm.call` |
| Real Runtime Eval Runner | `evalService.ts` calls `executeRuntimeRun`; built-in suite has 15 cases |
| Run Compare | `POST /api/compare/runs` and Run Compare UI |

## Acceptance Verification

- Studio Runtime Console launched a real Excel analysis Run.
- Live stream captured 17 Trace Events, 4 Context Snapshots, and 3 Tool Calls.
- Runtime executed `xlsx.inspect`, `filesystem.write`, and `python.run`.
- Runtime generated `fixtures/runtime-workspace/output/analysis_report.md` from real workbook statistics.
- Trace Viewer displayed the complete Trace Tree, Tool Call details, Artifact, and final output.
- Context Inspector displayed `system_prompt`, `skill_instruction`, `user_message`, `tool_descriptions`, `conversation_history`, and `tool_result` segments with token counts.
- Built-in real Runtime Eval suite executed 15/15 cases successfully with an average score of 5.0.
- Studio Eval Bench executed all 18 stored cases in one batch, proving the batch size exceeds 15.
- Run Compare displayed model, Prompt, Skill, tool chain, latency, tokens, final output, score, and a change ledger.
