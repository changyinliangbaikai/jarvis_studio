# 运行产物中心使用指南

在智能体（Agent）的任务执行中，其最终交付的核心价值往往体现在其生成的各类文件产物上（如数据分析 Excel 报表、生成的 PDF 摘要、或者是自动重构的代码文件）。

为了能够集中管理、在线预览并彻底追溯这些文件的生命周期与生成逻辑，Jarvis Studio v0.5 推出了全新的 **Run Artifacts (运行产物中心)**。

---

## 1. 产物中心大盘 (Artifacts Dashboard)

进入 `/artifacts` 页面即可访问产物大盘。在这里，系统会汇总整个项目在所有隔离沙箱（Eval Workspace）中产生的所有文件。

### 1.1 多维筛选与检索
- **按工作区过滤**：选择特定的 `workspaceId`，只查看该隔离环境下的产物；
- **按任务/场景过滤**：快速筛选出如“周报生成”或“代码审查”任务所产出的所有文件；
- **文件类型与命名过滤**：支持通过正则或关键字搜索文件名，或按文件后缀进行分类筛选（如只看 `.csv`、`.md`）。

---

## 2. 核心交互功能

产物中心为开发者与业务评估人员提供了以下便捷功能：

### 2.1 实时在线预览 (Preview)
- **富文本与代码高亮**：对 Markdown 报告、Python 代码、JSON 配置、HTML 等格式提供内置的语法渲染与高亮；
- **结构化数据表格**：针对 CSV、TSV 等数据文件，自动转化为交互式表格，支持列排序和关键字过滤；
- **媒体文件直显**：对 PDF 文档、PNG/JPG 图片以及 SVG 矢量图提供免下载直接预览。

### 2.2 最终定稿标记 (Mark Final)
大模型在同个测试任务下经过多次重放或 Resume 迭代后，可能生成了多个版本的文件。
- **标记 Final**：评估人员可在详情页将其中质量最佳的文件标记为 **"Mark Final" (定稿)**；
- **定稿链接**：定稿后，该文件将自动获得一个固定的 API 定稿链接，供外部下游系统或发布流水线直接读取；
- **状态联动**：被标记为 Final 的产物，其对应的测试任务（Test Task）在看板上会亮起绿色的“发布就绪”徽章。

### 2.3 产物打包下载 (Download)
- **单文件下载**：点击文件名旁的下载按钮直接下载原始文件；
- **任务级打包**：支持勾选整个测试任务，一键将该任务在工作区中产生的所有相关产物打包为 ZIP 格式进行下载。

---

## 3. 全链路元数据追溯 (Traceability Chain)

传统智能体产物最大的痛点在于：**“无法证明这个文件是如何被生成的”**。如果代码有 Bug，不知道是哪轮对话触发了错误的写入。

为了解决此问题，Jarvis Studio 产物中心将所有文件与系统的 Trace SDK 进行了深度的元数据绑定：

```text
                     产物中心文件 (Report.md)
                               │
       ┌───────────────────────┼───────────────────────┐
       ▼                       ▼                       ▼
 [Workspace ID]            [Task ID]               [Run ID]
定位所在的 Eval 沙箱      定位所属的测试任务      定位具体的执行周期
(workspace-excel-01)      (task-weekly-report)     (run-20260619-01)
                                                       │
                                                       ▼
                                                 [ToolCall ID]
                                             追溯至具体的工具 Span
                                           (e.g., file.write_file)
                                                       │
                                                       ▼
                                              [Trace Viewer 节点]
                                            - 审查大模型 Prompt 原文
                                            - 审查工具调用原始参数
                                            - 审查当时上下文 Token 状态
```

当您点击任意产物元数据中的 **ToolCall ID / Step ID** 时：
1. 系统会直接跳转至 **Trace Viewer** 页面；
2. 自动定位并高亮展开生成该文件的那个工具 Span 节点（如 `file.write_file` 或 `patch.apply`）；
3. 您可以直观看到**当时大模型的 Prompt 变量输入、LLM 的生成文本、以及工具执行的原始入参**，实现了“文件生成路径 -> 大模型心智决策 -> 运行环境”的无缝逆向回溯。
