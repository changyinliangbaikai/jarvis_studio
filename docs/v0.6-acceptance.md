# Jarvis Studio v0.6 Acceptance

## Product Flow

Jarvis Studio v0.6 is accepted when the daily workflow is visible and usable:

```text
Agent -> Prompt -> Playground -> Run / Trace -> Case -> Eval Suite
```

Advanced v0.5 modules remain reachable from Settings / Advanced, but they are not first-level navigation items.

## Key Scenarios

### Create Agent And Prompt

1. Open `/agents`.
2. Create an Agent.
3. Confirm a default Prompt draft is created and bound to the Agent.
4. Edit default model, Runtime, context strategy, tool policy, output mode, and tags.

Expected: the Agent can be selected in Playground and has a default Prompt Version.

### Run Prompt In Playground

1. Open `/playground?agentId=<id>&promptVersionId=<id>`.
2. Enter user input and optional variables.
3. Run.
4. Open the generated Trace.

Expected: a Run is stored, raw Trace events are preserved, and the Run metadata includes the historical Prompt snapshot.

### Convert Trace To Case

1. Open `/runs/:runId`.
2. Click convert to Case.
3. Open `/cases`.

Expected: the Case retains source Run / Trace, input, expected output, assertion mode, priority, status, and tags.

### Run Lightweight Evaluation

1. Create or select multiple active Cases.
2. Create an Eval Suite from `/evaluations`.
3. Run it against an Active Prompt Version.
4. Open the Eval Run result.

Expected: every Case execution creates a Run / Trace, results show pass/fail/error, and pass rate is calculated.
